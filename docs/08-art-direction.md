# 08 · Art Direction

On Deal uses the supplied Chog character design and community NFT artwork as visual texture
around the trading experience.

## Usage

- Official logo files live under `web/public/brand/`.
- Supplied NFT examples live under `web/public/art/chogs/`.
- The trades page collage labels these as sample community Chogs; it does not imply ownership,
  availability, or on-chain metadata for those images.
- Live token cards continue to use the connected collection's `tokenURI` through `ChogImage`.

The artwork should support the product: add an expressive, collectible mood through a playful
pinboard collage and the two-card Angel/Devil swap illustration, while keeping trade terms,
wallet state, and transaction actions clear.
